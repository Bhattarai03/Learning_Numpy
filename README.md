A hands-on repo for learning Numpy i.e. Python's core library for numerical computing.
Includes examples, exercises, and mini-projects covering arrays, vectorization, broadcasting,
and math functions to help beginners master data manipulation efficiently.

  Topics Covered
- NumPy arrays & operations
- Indexing & slicing
- Broadcasting & vectorization
- Mathematical & statistical functions
- Shape Manipulation
- Mini-projects & exercises
